# 实验一运行与答辩说明

本实验处理轨迹分段、方向规则去噪和 Douglas–Peucker 简化，随后用共同原始输入比较方案。实验一的 LLM 辅助系统、参数与顺序实验也包含在作业内；没有扩展到实验二的停留点或热点任务。

## 怎样运行

在仓库根目录使用现有 Python 环境：

```bash
.venv/bin/python -m task1.goal3 FULL_RECOMPUTE --output /tmp/sc_lab1_new_recompute
```

输出目录必须是新目录。这个入口从原始 JSON 和保存的真实历史提议重新执行处理、审核和画图；历史提议重放不算新的模型实验，默认新增记录级模型调用为 0。两份完成版 Notebook 也可以分别 Restart Kernel → Run All。基础 Notebook 重算参数、顺序、构造反例和全量生产；系统 Notebook 重算历史四模式候选及其选择。分别运行入口与 Notebook 会发生明确记录的重复复算。

`LIVE` 需要显式开关、独立的新 run ID 和原有授权认证，不是默认路径。`REPORT_BUILD` 从核验结果重建摘要、图、报告和实际待审 ZIP，拒绝覆盖已有 ZIP；新产物仍需独立验收。完整命令见 [实验一 README](../../README.md)，实际执行证据见 [当前审阅入口](../../evidence/goal3/REVIEW_PACKET.md)。

## 最终方法是什么

两个策略都采用 **S → D → P**。方向阶段只计算一遍标记并同时删除；首尾与必要方向不可计算的窗口保留并标记，下游重新计算特征。

| 参数 | 教学参考 R0 | 最终 S0 | 单位 |
|---|---:|---:|---|
| 相邻时间分段阈值 | 30 | 30 | 源时间秒 |
| 相邻距离分段阈值 | 400 | 400 | 条件化工作米 |
| 最少片段点数 | 5 | 2 | 原始点 |
| 最短片段长度 | 65 | 0 | 条件化工作米 |
| 方向阈值 | 35 | 35 | 度 |
| DP 阈值 | 5 | 5 | 条件化工作米 |

S0 取消正长度下限属于本轮批准参数域中的选择。教学参考的短段过滤实现、参数实验和被过滤结果仍完整展示；没有把老师的短段任务删掉。最终逐记录处理使用固定确定性工具，没有在线 LLM、搜索或记忆依赖，也没有临时添加逐记录回退。

## 为什么没有采用开发集上更强的组合

开发集包含已暴露的 240 条记录。S0 通过保护后，一个仅依据当前记录原始时间差的分组方向规则与它组合，形成 S0_G0；该组合在开发集相对 S0 有 41 条共同几何严格改善。

但冻结短名单在另外 240 条选择记录上比较后，G0 与 S0_G0 都在 `3017、9311、9534` 上违反共同几何非退化条件。独立原始重算确认：方向阶段保留更多点，改变了后续 DP 的保留索引；两边的即时 DP 误差仍小于 5 工作米，原始共同集合上的最大误差却增加。这是方法权衡，没有把它当成实现错误“修到胜出”。S0 在选择集全部保护通过，增加共同覆盖 6,625 点，因而按冻结规则进入最终确认。

600 条预先保留记录上的一次性确认支持 S0：全部固定保护通过，349 条增加覆盖，共同覆盖由 35,868 增至 62,220 点，实际存储点由 10,991 增至 12,114 点。参数没有根据这批结果调整。该有限样本结果不构成普遍最优或真实噪声识别准确率的证明。

DP 参数 2 在相同上游输入下保留更多点，未证明压缩收益；参数 10 及其组合实际超过共同 5 工作米预算。完整负结果和移除组件检查见技术报告及 [A3 裁决](../../evidence/goal3/A3_DECISION.json)。

## 指标最容易混淆的地方

- **共同 raw 覆盖**按原始点身份和固定原始窗口定义；它不是最终文件里的点数。DP 删除的存储点仍可能被输出折线覆盖。
- **共同几何保护**比较候选在参考已覆盖集合上的最大几何误差，不能换成候选自己的 clean 输入，也不能用其他记录的平均改善抵消某条记录的退化。
- **即时 DP 误差**只针对 P 的完整实际输入。方向阶段已经删去的 raw 点不在这个误差保证内。最终确认的共同 raw 最大误差约为 280.697 工作米，而即时 DP 最大误差约为 4.997 工作米；两者参考对象不同。
- **新增覆盖的反例**：全量 record 352 的四点窗口被 R0 因点数不足过滤；S0 保留片段后，D 删除原索引 105，产生约 266.017 工作米的 raw 偏差。该局部 P 没有再删除点。这一经独立重算的例子说明扩大覆盖不能替代真实噪声判别。
- **点终态**区分分段后过滤、方向删除、DP 简化和最终保留，全部原始点都进入账本；合法空输出也保留记录分母。
- **工程核验通过**说明实现、身份、范围和产物满足合同；**SUPPORTED_WITHIN_SCOPE**说明有限范围读数满足预登记规则。这两种判断不能互换。
