## 4. 处理链与点身份

参考参数 `dt=30,distance=400,min_points=5,min_length=65,direction=35,dp=5`，参考顺序 S-D-P。S 是当前索引上的分段后立即短段过滤；D 是一次标记后同时方向删除；P 是 DP。六顺序全部登记，S 之前仅保留原始记录边界，不能暗加时间/空间分段。

每阶段重新计算当前邻接的距离、dt、速度和方向。S 在 `dt>dt_threshold`、负 dt 或 `distance>distance_threshold` 边的右点前切开，等号不切，边右点只属于新段；段内点数不足或累计长度不足分别保存过滤理由。D 保持教师双侧环形方向差均严格大于阈值，保留首尾、必要方向缺失与零位移窗口，不迭代。P 用有限线段距离，保首尾、等号不递归、退化线段按端点距离；dp=0 保留所有点，是无精简参考。

每原始 `(record_id,index)` 恰有一个最终状态：`FILTERED`、`DIRECTION_REMOVED`、`DP_REMOVED` 或 `RETAINED`；拒绝/阻断的输入另有明确未处理状态。全部过滤记录仍在输入与记录分母。保存各阶段输入/输出索引、特征、删除与保护原因、阶段长度、P 完整输入和即时输出。若 P 后有 D/S，其额外删除不能计入 P 省点率，最终误差也不能冒充 P 即时数值保证。

浮点审核只采用 G1 固定规则 `64*binary64_epsilon*max(1,extent,abs_coordinate,tolerance)`；方向派生角差用 `64*eps*360`。不把审核余量加进算法阈值，不放宽候选容差来通过。

## 5. 共同参考、指标与安全保护

共同原始参考在处理候选前构造：每 raw 记录按 `dt>30 or dt<0 or distance>400` 形成原始索引窗口，不做短段过滤或方向删点。其 hash 属于可信父句柄。候选不能从自己的 clean 反推共同参考。

对每个 raw 点 p：若最终保留，其共同参考距离为 0；否则只有在**候选同一最终片段**的相邻保留索引 a<p<b 且 a、p、b 属于同一原始参考窗口时，计算 p 到有限线段 a-b 的距离。其余为 `null+UNCOVERED_OR_NO_BRACKETING_EDGE`。单点原始窗口只有自身保留才可覆盖。保留完整逐点距离/不可用理由，覆盖数/全部原始点数，不能用过滤后点数作分母。

任一最终同片段相邻索引 a<b 跨过原始固定断点即 `raw_breakpoint_crossing`；计跨越边数、唯一断点数、断点触发点是否被 P/D 先删除及最终两側输出。该诊断不暗中修复输出。跨越数>0 是顺序/候选的安全拒绝条件，仍保留实际输出作为实验负结果。

必报：输入/各阶段记录、片段与点去向；各过滤原因与整条无输出比例；raw→final 保留率和记录覆盖；P 即时省点率 `1-N_P_out/N_P_in`；P 完整输入的索引区间 max/mean/分位误差与超界点；共同 raw 窗口误差及其覆盖；阶段长度与相对变化；方向/速度可计算性、时间/重复/方向异常诊断；原始断点/邻域变化；逐记录、逐层配对；失败、退化、成本。`all_filtered_record_ratio` 专指该记录全部原始点的终态均由 S 过滤；`record_no_output_ratio` 指最终完全无输出，允许之前已由 D/P 删除部分点。两者在换序实验中可能不同，分别计数。

空参考、零长度、缺可用输出、不可算时间/方向均 `null+reason`，原分母仍输出。汇总既提供计数之比，也提供记录统计分布及有效/不可用记录数。若记录级 mean 忽略 null，必须显示原记录数、有效数、原因，不把不同可计算集合的均值直接判优。主要统计单位是原始记录；三 episode 不是三倍独立样本。本轮默认不作置信区间或显著性宣称。

## 6. 候选、可行集与选择

工程层先独立核验原始身份/值、链路、账本、版本和指标；工程错误必须修复。之后安全层检查原始断点不跨越、P 实际误差不超其登记容差、完整覆盖登记。正确执行的失败/无收益是有效结果。

参数实验的完整可行集与多指标 Pareto 表全部保留。C-S 仅改变 S 的四参数组；C-D 仅改变 direction；C-P 仅改变 dp。始终 S-D-P，不叠加三个候选。C-S 的开发域是规定两个 5×5 小网格的并集，不扩展成四参数全组合。参考值可作为每个单项的最终操作性回退。

C-P 上游 S/D 完全相同，完整 P 输入一致，共同误差预算固定 `5` 工作米。允许在此预算内比较 P 省点率；dp=10/20 仅当实际每条误差仍≤5才可能可行。保护：完整 P 输入参考相同、首尾与 raw 窗口覆盖无下降、无原始断点跨越、每条实际 P 误差≤5+固定审核余量。主指标是省去至少 1 个点；阶段长度变化单列描述，不把长度缩短当恢复质量。可行时选总 P 输出点数最少，若同量则实际 max P 误差较低；再并列保留 reference（reference 不在并列集时按较低 dp 后 canonical ID 取可重复代表），完整并列/Pareto 集不丢弃。这是预算内压缩结论，不是整体清洗质量接受。

C-S/C-D 的主要读数是共同 raw 覆盖改善或共同几何误差下降，不以多删/多留本身判优。每条记录保护：候选覆盖点身份集合包含 reference 覆盖集；在 reference 已覆盖点集合计算的候选 max 误差不高于 reference+固定数值误差；原始断点跨越为0；原有非空记录/窗口覆盖不能丢失。新增覆盖点误差另报；baseline 空或比较误差不可计算时不能把 null→数值算成几何改善。严格收益须有至少一个覆盖计数增加或同参考误差下降超过数值余量，其余保护不退化。对多项不可比或并列可行改进保留 reference 作为操作性选择，同时完整保留备选。未经标注真值仅可标 `SUPPORTED_WITHIN_SCOPE`，绝不 `QUALITY_ACCEPTED`。

模式从已评价的候选选择：先工程与断点安全，再相对同记录 reference 应用上述 S/D 共同覆盖/几何保护；仅当上游与 reference 相同时允许按 C-P 的共同5米预算换取压缩。非支配候选多于一个且不可比时回退 reference，记录原因；llm-only 的唯一合法锁定提议也照样报告 proposal 和独立评分，若执行层需 fallback 则单列，不用 fallback 掩盖原始提议失败。没有预先有效标量质量目标，本轮 normalized regret/bounded-search scalar gap 均不适用；报告逐指标有符号差值。

所有实质结论从 `SUPPORTED_WITHIN_SCOPE / NO_DEMONSTRATED_GAIN / TRADEOFF / REJECTED_BY_CONSTRAINT / INSUFFICIENT_EVIDENCE` 选，工程状态另列。G2_EVAL 仅确认冻结候选和代表配置，不能看完再调参数。若实现错误影响模型看到的反馈，相关后续提议与整个 episode 失效并重建 LIVE 决策链。

额外两类结构候选本轮登记 `NOT_ADMITTED_WITH_REASON`：没有经独立标注支持的运动真值，且尚无适用的低位移可靠性边界；在完成规定实验前不新增策略/保护阈值以凑候选数量。这不影响三个参数单项要求。若 A 在开发证据后提出边界内结构候选，必须新版本登记完整定义并经 C 审核且在 G2_EVAL 前冻结，最多两类各一个，不自动获准。

## 8. 四模式、决策反馈与真实成本

共同模型配置由实际 Provider 能力核查绑定：`gpt-6-astra`、reasoning `medium`、超时180秒；不能设 seed 时记 unavailable。同一主体提示模板、诊断字段、合法参数网格、工具和审核。一次真实模型调用最多8张诊断卡；每记录独立候选、预算和结果。一批响应记一次可见模型派发，不写成8次 provider 请求。

诊断卡仅含 raw 点数、bbox跨度、时间差、重复与原始断点等统计及可信句柄，不包含完整原始坐标序列、其他模式中间结果或 G2_EVAL 锁定后评价。`llm-only` 没有搜索反馈和记忆，一次提议锁定后才执行评分；无隐藏修正。`search-only` 纯确定性，从reference开始严格0实验模型调用，并用一调用即失败的接口哨兵测试。

共同有限搜索序列20个：reference；dp=0,1,2,10,20；direction=15,25,45,60；dt=15,60；distance=95,800；min_points=2,3,7；min_length=0,32.5,130；每一项只改所列参数。此序列在看记录结果前固定，覆盖不完整且不称最优。LLM 可在六参数各自网格内提完整参数向量，不限这20项；没有新增算法。

两个搜索型 LLM 模式最多3决策回合：第一轮一个起点，执行reference+合法提议，再按固定序列补到至多8候选；第二轮只见自己已有实际反馈，可提最多2候选，补到至多14；第三轮同样最多2候选，补到至多20。允许明确 stop 提前锁定，预算是共同上限而非伪称实际相同。重复配置记 cache/replay read 不重复算独立候选；非法参数原样存证后拒绝，不夹紧。允许反馈的模式可用剩余回合修正，llm-only 不可。

每轮存原始请求/响应、可见request/session ID、输入卡/反馈/记忆哈希、提议、动作、理由与实际结果。预测在执行前绑定 `metric_id/reference_handle/predicted_sign`；仅数值可比且变化超余量时判符号，未承诺/不可用/近零分别计分母。最终锁定评分单独执行且不返流当前决策。

成本分别为 governance_role_dispatches、experiment_model_dispatches、deterministic_tool_calls、candidate_evaluations、replay_or_cache_reads、可见wall time/tokens/provider IDs。治理 A/C 不给运行中的 search-only 参数反馈。底层请求/费用不可见则 unknown。服务临时失败同请求最多2次重试，遵守Retry-After；auth/权限/计费阻碍不重试绕过。超时先确认原进程状态，不能重复派发。

## 9. 记忆与隔离

只从 DEMO_MEMORY 60条生成情景记录；确定性处理与候选核验通过才准入。无收益案例仍可保存但保留结果性质，不能标成功。程序记忆只由已核验示范记录统计出建议参数/区间；人类知识只链接真实教师/用户内容，没有内容就空，不伪造人类笔记。工作记忆只保留当前 episode 并在结束清空。

检索用相同描述层 gate 和6个可解释原始特征：log1p(point_count)、log1p(span)、log1p(median_positive_dt)、zero_dt_fraction、adjacent_duplicate_fraction、raw_break_fraction；尺度仅由 DEMO_MEMORY 的 min/max 固定，常量维度记0。同层候选按归一化欧氏距离、memory ID稳定排序取最多3条；无同层条目返回空，不从别的模式或评测记录填充。过滤同record/关联group、非DEMO、错raw/contract/snapshot版本及未核验记录，记录所有拒绝原因。

正式评测前冻结一次快照；开发修索引仅能用同60条并重做开发检查，不许看G2_EVAL后扩充。各episode只读同一hash。前后hash、写入拒绝、自检索拒绝、跨episode工作记忆清空测试必须通过。

消费分层报告：retrieved→eligible→delivered→model_cited→action_consistent。要求提议提供 `memory_ids_used` 与与实际准入内容相符的解释；此为可观察消费，不是因果增益证明。同record同episode编号与无记忆模式的建议差异另报，它们是独立真实调用，差异不能独自归因于记忆。LLM 不拥有持久记忆写工具。
