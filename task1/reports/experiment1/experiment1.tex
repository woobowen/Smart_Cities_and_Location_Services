\section{数据、任务与结论边界}
\begin{finding}
本实验实现分段与短段过滤、方向规则删除、Douglas--Peucker（DP）简化，并通过参数、顺序和 LLM 辅助实验检查这些操作的影响。评价首先保护原始记录、原始断点和共同几何覆盖；数据没有噪声真值，因此不把“删得多”或“留得多”解释为识别准确率。
\end{finding}

\subsection{时间、坐标与可计算性}
使用源数据的秒级时间差，不添加时区推断，也不改写时间。时间差为零时速度不可计算，保留缺失原因；位移为零时方向不可计算，不能用数值零表示正北方向。不可计算不是已证实噪声。

原始来源坐标系统仍为 \texttt{UNVERIFIED}。在用户批准的条件化分析下，固定椭球半长轴 $a=6\,378\,137$ m、反扁率 $1/f=298.257223563$，统一令椭球高 $h=0$。固定 ENU 中心为 $(\lambda_0,\phi_0)=(121.343555^\circ,31.3561015^\circ)$，它来自早期 pilot 包围盒，未按候选得分选择。

对弧度制经纬度 $(\lambda,\phi)$，设 $e^2=f(2-f)$、$N_\phi=a/\sqrt{1-e^2\sin^2\phi}$，先计算
\begin{align}
X&=(N_\phi+h)\cos\phi\cos\lambda, &Y&=(N_\phi+h)\cos\phi\sin\lambda,\\
Z&=[N_\phi(1-e^2)+h]\sin\phi .
\end{align}
减去固定中心的 ECEF 坐标后，工作平面坐标为
\begin{align}
E&=-\sin\lambda_0\Delta X+\cos\lambda_0\Delta Y,\\
N&=-\sin\phi_0\cos\lambda_0\Delta X-\sin\phi_0\sin\lambda_0\Delta Y+\cos\phi_0\Delta Z.
\end{align}
这与 PROJ 官方文档所述的地理坐标到地心直角坐标、再到固定原点 ENU 的转换语义一致\cite{proj-cart,proj-topocentric}。本文的“工作米”表示这个数学模型中的长度，不证明输入 datum，也不等同绝对定位精度。未设置一个 EPSG 标签来替代来源证明，未做坐标加偏转换，未叠加道路底图。

G2 在 307 条、30,992 点上用同一假设椭球的独立 PROJ 路径核对坐标，最大差约 $4.82\times10^{-10}$ 工作米，小于 $10^{-6}$ 的实现核验容差。该范围内对 1,594,527 个记录内点对比较 ENU 距离与椭球测地距离，最大绝对差为 3.503584 m、最大相对差约 0.015054\%。两者是近似模型的差异，不能写成测量误差。实际开发与 G2 评估处理轨迹的敏感性检查未观察到登记阶段动作差异；这只是已检查范围的结果，G3 扩大核验另列。

\section{处理方法与明确约定}
\subsection{S：分段与短段过滤}
对当前输入的相邻点，若 $\Delta t>\tau_t$、$\Delta t<0$ 或工作距离 $d>\tau_d$，在右侧点前断开。等于阈值不分段；右点属于新段，不复制边界点。段内累计长度只累加未切断的边。

分段后，点数少于 $n_{\min}$ 或累计长度小于 $L_{\min}$ 的段被过滤；两个条件同时成立时保存两个原因。完整保留参考过滤实现，才能比较取消正长度下限与降低点数门槛的影响。$L_{\min}=0$ 不代表真实短段已经被证明有用，更不代表教师取消了短段过滤任务。

\subsection{D：方向异常候选的单次同时删除}
对可计算边定义当前点到下一点的出边方向
\[
\alpha_i=\operatorname{atan2}(E_{i+1}-E_i,N_{i+1}-N_i)\pmod {360^\circ},\qquad
\delta(a,b)=\min(|a-b|,360^\circ-|a-b|).
\]
只有 $\delta(\alpha_i,\alpha_{i-1})>\theta$ 和
$\delta(\alpha_i,\alpha_{i+1})>\theta$ 同时成立，才把点 $i$ 标为待删除。先在本阶段完整输入上计算全部标记，再同时删除；不边删边改邻域，不迭代到收敛。首尾、缺少必要后继方向和零位移方向窗口保留并标注原因，后续阶段重算特征。这一执行次序来自已保存的 D2 用户授权。

方向规则只指出局部形状变化，真实折返也可能触发，连续噪声也可能不触发。未引入未知交通方式的物理限速，也未把低位移阈值当作测量真值。

\subsection{P：有限线段的 DP 简化}
对于端点 $a,b$ 和区间内点 $p$，使用有限线段距离
\[
u=\operatorname{clip}_{[0,1]}\frac{(p-a)\cdot(b-a)}{\|b-a\|^2},\qquad d(p,[a,b])=\|p-a-u(b-a)\|.
\]
当端点重合时直接取点到端点的距离。若区间最大距离严格大于 $\varepsilon$，保留最远点并递归；否则只保留端点。$\varepsilon=0$ 被明确约定为不简化、保留所有输入点。输出沿用原始索引、坐标和时间。

DP 的误差保证针对\textbf{它的完整即时输入}。若 DP 之后再删点，最终折线必须另算误差；不能沿用 P 阶段的证书。方向阶段已经删掉的点也不属于自身 P 误差的分母。

\subsection{参数与点去向}
教学参考 R0 为 S--D--P，参数
$(\tau_t,\tau_d,n_{\min},L_{\min},\theta,\varepsilon)=(30,400,5,65,35,5)$，单位依次为秒、工作米、点、工作米、度、工作米。课件中的 95 m 是骑行示例阈值；没有把它静默替换为本工程的参考配置。

每个原始点只具有一个最终状态：S 过滤、D 删除、P 删除或最终保留。阶段轨迹另外保存输入、标记、输出和原始索引，所以可以分清“覆盖到该原始点”和“实际存储该点”。全过滤记录仍出现在结果和分母中；未完成或失败不能用合法空输出代替。

\section{评价：共同参考先于候选}
\subsection{原始窗口、覆盖与几何偏差}
在所有候选之前，用固定 $\Delta t=30$ 秒、距离 400 工作米及负时间差切出共同原始窗口，不应用短段过滤。对于原始点 $i$，若被最终显式保留，则几何误差为零；否则必须存在同一个最终段内相邻保留索引 $a<i<b$，且三者处在同一共同原始窗口，才计算 $d(p_i,[p_a,p_b])$。没有这样的夹持边时记为不可用，并保存原因。

设 $C(M)$ 为策略 $M$ 下可计算共同误差的原始点身份集合，则
\[
\operatorname{coverage}(M)=\frac{|C(M)|}{N_{\rm raw}},\quad
\operatorname{retention}(M)=\frac{N_{\rm final}}{N_{\rm raw}}.
\]
两者的分子不同。原始点落在保留边内部时计入覆盖，但没有被存储。几何误差衡量相对原始折线的保护，不是到真实道路或真实位置的误差。

S、D 及其组合相对固定 R0 和当前已接受策略分别检查：原有覆盖集合不能丢失；原有非空记录和窗口不能丢失；不得跨越原始断点；在参考已覆盖点集合上的最大几何误差不能退化。通过全部保护后，覆盖至少增加一个点，或可比较的最大误差下降超过固定浮点余量，才能称为范围内严格改善。不可用变成可用可形成覆盖收益，不能算几何误差下降。新增覆盖点的误差另外报告。

\subsection{P 的局部指标与整体指标分开}
P 省点率为 $1-N_{P,\rm out}/N_{P,\rm in}$，最大误差遍历完整 P 即时输入与对应输出区间。当输入为空，误差和省点率都不可用，不赋值为零。只有上游完全相同、P 完整输入相同且实际误差满足共同 5 工作米预算时，才能比较 DP 省点收益。改变 S 或 D 后得到的更高省点率只作描述，不能归因于 DP 变好。

浮点审核余量为 $64\epsilon_{64}\max(1,\text{范围},|\text{坐标}|,\text{容差})$；角度余量为 $64\epsilon_{64}\times360$。它用于数值比较，不改变实际算法阈值。不对不同指标临时加权形成总分；没有预先固定可比标量目标时，normalized regret 保持不可用。

\subsection{数据使用边界与版本身份}
G2 固定 7 条 pilot、60 条示范记忆、120 条开发、120 条 G2 评估以及 11,079 条 G3 保留记录。按记录完整身份与已核实关联组划分，不能拆片段制造独立样本。描述性分层使用原始跨度、时间异常标记和重复位置标记，不能解释为真实运动类别；稳定哈希 seed 为 42。分层样本的简单均值不代表总体均值。

G2 开发包含 \DevelopmentConfigs{} 个唯一参数配置，G2 评估包含预登记的 \EvaluationConfigs{} 个代表配置。G2 评估结果在进入 G3 时已被查看，因此它保持历史评估身份，可以补充开发，不能再次改名为独立最终确认。将选择集与最后确认集分开，是为了限制有限样本上的反复选择偏差；Cawley 与 Talbot 的论文摘要支持这一一般风险，但不提供本任务的样本量或最优参数\cite{cawley2010}。

\subsection{C-S 的覆盖收益及未胜出的单项}
G2 选出的 C-S 只把 $n_{\min}=5$ 改为 2、$L_{\min}=65$ 改为 0，其余参数保持 R0。G3 将此历史候选记作 S0。它在 G2\_EVAL 的 120 条记录中全部通过预登记保护，\CSStrictRecords{} 条严格改善；共同覆盖由 \RZeroCovered{} 增至 \CSCovered{}，新增 \AddedCovered{} 个覆盖点，无输出记录由 \RZeroEmpty{} 降为 \CSEmpty{}。

这支持“参考短段过滤在该样本上损失了可恢复的几何覆盖”，没有证明新增点全都干净。共同误差超过 5 工作米的点从 249 增至 250，而 P 即时误差仍不超过 5，直接说明两个误差参考不同。最终显式保留点从 \RZeroFinal{} 增至 \CSFinal{}，也远小于共同覆盖点数。

\subsection{六种顺序}

D 在分段之前可能跨越本应断开的窗口；P 在 S 之前可能删除触发断点的点，使后续 S 看不到原始边。这些是实际输入序列变化造成的风险，不能事后隐含预分段、再仍称为相同顺序。四种危险顺序被拒绝后没有进入正式候选。

S--P--D 在开发及 G2 评估中未发生上述安全失败，但出现真实多指标权衡，没有替换参考 S--D--P。由于 P 后面还有删除，它的 P 即时误差不代表最终误差；报告保留 raw 到 final 的独立读数。

\subsection{四种结构与相同预算}
LLM only 只根据原始诊断提出参数，没有搜索反馈或记忆；提议原样验证后执行，再作评价。Search only 使用预先固定的 20 个配置序列，记录级模型调用严格为零。LLM + Search 允许最多 3 个反馈回合，累计候选上限依次为 8、14、20；LLM + Memory + Search 在相同流程上增加只读示范检索。每批最多 8 张诊断卡，一次批调用不能按卡数重复计数。非法提议不得偷偷截断到合法值，失败与回退均须入分母。

\subsection{记忆被使用，不等于产生因果收益}
示范记忆只来自 \MemoryDemo{} 条 DEMO 记录，其中 26 条在登记比较中获得支持，34 条无新增收益；其 SHA256 为
\begin{quote}\small\nolinkurl{2330543c3a443532891936ac29d4080cb6e5f45c58e2976cc81c8fa67c6607d6}。\end{quote}
检索用 6 个原始诊断量：点数、空间跨度、正时间差中位数的 $\log(1+x)$，零时间差比例、重复位置比例和原始断点比例。缩放范围只用示范集确定；固定描述性层内最多检索 3 个最近邻，排除自身及关联组，距离并列用稳定身份排序。没有额外的人写知识条目，也没有把评估记录写回长期记忆。

开发与 G2 评估合计 96 次带记忆记录观察都收到检索结果；241 个决策回合中 60 个引用记忆，49 个满足已登记的动作一致判断。这三个分母分别对应送达、引用和决策动作，不能混用。评估阶段带记忆与不带记忆的 LLM + Search 均有 47/72 个支持输出，所见候选与 episode 又存在差异，因此不足以证明因果质量收益，也不足以证明所有情形等效。

\section{解释、局限与复现}
\subsection{结果能说明什么}
G2 支持降低短段过滤造成的覆盖损失，保留了无单项收益、危险顺序和合法 AI 权衡提议。它没有证明某个参数具有普遍清洗最优性，也没有证明增加 LLM 或记忆一定带来收益。
\input{conclusion_generated.tex}

本文没有真实道路、运动类别与测量误差标签。原始点的几何保护有助于防止删除过程悄悄破坏数据，却不能辨识所有真实噪声；提高覆盖可能同时保留近静止、短片段或异常位置。源 datum、时间来源和记录独立性仍限制地理解释。工作坐标数值核对只验证指定模型实现，无法反证这些来源限制。

引用的两份 PROJ 文档只支持数学转换语义和独立核算；Cawley--Talbot 仅核读官方摘要与元数据，借鉴有限样本选择可能过拟合的提醒。本文没有声称完整复现该论文或其理论结论，也未把论文中的机器学习实验移用为本数据集证据。
