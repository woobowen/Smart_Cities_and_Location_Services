G3\_RESERVED：其余记录，本轮不用于候选选择、模式评估或最终清洗。

四种 LLM 模式另从 DEVELOPMENT 和 G2\_EVAL 各预先固定 24 条共同样本，以控制真实模型成本。必须在查看方法结果前选定并登记；四种模式使用完全相同的 24 条，不从效果较好的记录中挑选。

这些数量是本 Prompt 的实验规模设置，不是教师要求或总体代表性证明。原始数据全量只读盘点允许，不能称为完成全量清洗。

沿用已有、可解释且与本轮结果无关的诊断类型规则分层抽取，尽量覆盖静止样、混合样、行驶样及时间／重复异常。不得将高重复率直接等同于静止真值。

如现有类型规则未经核验，先在开发准备阶段固定纯描述性分层规则；不得用候选处理结果定义分层。可采用原始运动跨度的低／中／高分位层，并明确不是经过标注的运动类别。

采用记录分组与固定 seed=42 的稳定排序／哈希抽取，记录算法、完整 ID、分层规则、父记录关联与哈希。已知被历史实验反复使用的记录标记 exposure，不宣称它们从未被观察。

类别数量不足时按预先记录的确定性再分配规则取样，报告缺口，不复制记录凑数、不以替换“难例”改善结果。必须声明分层样本与总体分布的区别，不能直接将等额分层均值称为总体均值。

## 8. 评价合同：正确执行、研究效果和最终采用分开

### 8.1 工程硬条件

每个原始点有唯一可追踪身份和终态；所有输入记录均进入结果登记，全部过滤也是合法终态，不能从分母消失。

必须核对：来源与完整输入集合、原始值不变、索引有序、不跨记录连接、边界归属、过滤理由、方向调度、DP 有限线段距离、阶段特征重算、实际输出与账本、汇总和版本一致性。

DP 数值保证针对“本次 DP 的完整输入参考”。保留首尾、阈值等号不递归、退化线段按端点距离处理，沿用已批准浮点审核尺度，不能为候选放宽。

缺失值、零长度、空参考、不可计算速度／方向、缺可用输出等，以 null + reason + 原分母报告，不默认填 0 或从统计中删除。

Goal 2 的新参数、顺序和候选使用独立登记的新合同及对应审核器；保留 Goal 1 冻结合同和旧回归能力。不得通过改写旧批准文件、删除 allowlist、跳过检查或放宽旧合同来让新候选通过。不同顺序的阶段输入、DP 参考及后续删除须按其实际计算链独立验证。

### 8.2 必需的效果读数

至少包括：

- 记录／片段／点数的阶段去向，全部过滤记录比例，各过滤原因。
- 相对共同原始范围的点保留与记录覆盖；与 DP 省点率分开。
- DP 省点率：1 - N\_final\_DP / N\_input\_DP。
- 最大、分位数或均值索引区间误差及超界点；注明参考和单位。
- 各阶段长度变化、可计算性与异常诊断变化，明确它们是描述性读数。
- 与固定参考阈值相关的原始断点是否被跨越／遗漏，及输出覆盖情况。
- 分类型结果、逐记录配对差异、失败和退化案例。
- 原始 LLM 提议合法率、实际执行率、拒绝原因、建议方向与实测方向一致性。
- 记忆检索命中、适用性、消费情况和前后哈希。
- 实际资源消耗，作为成本信息，不将本项目改成性能优化课题。

跨不同去噪结果时，不能拿每个候选自己的 clean 作参考，比较它们的 DP 误差后声称整体质量提升。专项 DP 保证与跨方法共同参考评价必须分开。

需要共同参考时，在运行候选之前固定其来源、索引窗口、覆盖定义与不可用规则；不能从候选输出反推有利参考。缺乏真值时，只能评价条件化几何保真、约束满足、覆盖和权衡，不能输出真实误删率、噪声检测准确率或真值恢复率。

### 8.3 阶段选择与收益判断

禁止自动沿用 starter 的旧加权综合目标、旧 regret 分母或未经批准的“质量分”。

先按工程正确性判断可审查性，再按实验专属硬约束与保护项判断可行性；完整保留可行集及其多指标 Pareto 关系，不为了强行挑出冠军临时发明权重。

对相同输入、相同上游处理的简化实验，允许在预登记共同误差预算内比较省点率；方向去噪与分段实验没有真值时，不以删除更多或保留更多单独判优。

自动进入 Goal 3 候选名单的保守规则：在可比定义和共同参考下，至少一项预登记主要指标严格改善，全部预登记保护项不退化；数值差异须超过固定数值误差范围。整数指标至少实际改变 1 个计数。若涉及真实质量但证据不足，即使描述性指标改善也不标成 QUALITY\_ACCEPTED。

不允许事后设置可接受退化额度。需要非零退化容忍且没有已批准依据时，报告 TRADEOFF、保留备选，留给 GPT＋用户最终判断，不因此停止其他实验。

允许的实验结论包括：SUPPORTED\_WITHIN\_SCOPE、NO\_DEMONSTRATED\_GAIN、TRADEOFF、REJECTED\_BY\_CONSTRAINT、INSUFFICIENT\_EVIDENCE。它们与 ENGINEERING\_VERIFIED 分列；无增益不等于工程失败。

如为兼容单次调用必须返回一个候选，可按预登记的保守规则选取阶段候选；多项不可比或并列时保留参考配置，仍输出完整候选集。不能将这种操作性回退解释成参考方法最优。

只有固定了有效标量指标和方向时才计算 bounded-search gap。搜索仅是有限预算参照，不是真值或全局最优；LLM 优于参照时保留有符号差值，不截成 0。headroom 为零、过小或指标不可比时，归一化 regret 记不适用，报告绝对差值或逐指标差值。

## 9. 规定实验一：三组参数敏感性

先在本轮代码上真实重跑教学参考链：

分段 → 短片段过滤 → 一次标记、同时方向删除 → DP。

参考配置：LIMIT\_DT=30、LIMIT\_DISTANCE=400、LIMIT\_POINT=5、LIMIT\_LENGTH=65、LIMIT\_DIRECTION=35、DP\_THRESHOLD=5。时间按已确认相对时间单位，距离统一称工作米。该配置是 reference，不是已选最优。

以下网格是本 Prompt 新设的探索值；若教师原件明确指定必须运行的其他取值，另外完整覆盖并说明来源，不能静默替换。

分段与过滤组：

- 时间阈值：[15, 20, 30, 45, 60]。
- 距离阈值：[95, 200, 400, 600, 800]。
- 最少点数：[2, 3, 5, 7, 10]。
- 最短累计长度：[0, 32.5, 65, 97.5, 130]。

每项先做单因素实验，其余维持参考配置。再做时间×距离的 5×5 小网格，以及点数×长度的 5×5 小网格，区分断点规则与短段过滤作用；不扩展为所有因素全笛卡尔积。

95 工作米仅是纳入对照的教学示例数值，不将骑行示例的 25 km/h 写成本数据已确认限速。dt=15 会切开大于 15 的间隔，不能重复“15 能保住 20 秒”的旧错误解释。

去噪组：方向阈值 [15, 25, 35, 45, 60] 度。调度始终沿用一次标记、同时删除；首尾和必要方向不可计算窗口保留并标记，删除后重新计算特征。

简化组：容差 [0, 0.5, 1, 2, 5, 10, 20] 工作米。0 按现有合法实现保留全部点，作为无精简参考，不能称为最简解。

本节首先在 DEVELOPMENT 全部 120 条上完成。每组整理完整结果与稳定区间；候选锁定后，在 G2\_EVAL 全部 120 条上评估预登记的代表配置和单项候选，不利用评测结果再次选择最优参数。

同一配置可以复用本轮同版本的有效计算，但要保留共同 experiment key 和来源，不能将复用当成多次独立实验。

## 10. 规定实验二：顺序对照与依赖解释

S 表示分段＋该次分段后立即进行的短片段过滤；D 表示既定一次性方向删除；P 表示 DP。

登记六种顺序：S-D-P、S-P-D、D-S-P、D-P-S、P-S-D、P-D-S。

每个阶段都基于当前索引计算，不能使用旧速度或方向；没有执行 S 之前，不能偷偷先做同样的距离／时间分段，让“交换顺序”成为假对照。任何共同输入保护必须显式定义并对全部组一致。

参考为 S-D-P，其余是受控顺序实验，不是允许直接部署的不受限处理链。保留原始记录边界，所有输出仍可追踪。

要实际检查：

- P 在 S 前是否移除了触发原始时间／距离断点的点。
- D 在 S 前是否让原本应切分的异常连接消失，或者在间断两侧构造了不合理方向窗口。
- P 在 D 前是否改变邻域结构和方向判断。
- 短片段过滤对不同阶段输入的累计长度、点数与整条丢失率有何影响。
- 最终输出是否满足共同的原始断点保护与覆盖要求。

不能为了让某个顺序通过，暗加另一组没有的修复步骤。需要先分段才能成立的安全变体，另列为受保护版本，明确并非原来的朴素顺序。

违反共同安全条件的顺序，保留实际诊断产物并标 REJECTED\_BY\_CONSTRAINT，不作为有效改进候选；这种有证据的拒绝是实验结果，不必把方法修到“必然通过”。

在 DEVELOPMENT 完成所有六种的实际小规模至全开发样本检查；对不安全组至少保留可复算的具体失败证据，不必无意义扩大运行。可行顺序冻结后按共同 G2\_EVAL 比较。不得以“理论上不合适”替代全部实际对照。

## 11. 规定实验三：真实四模式与公平预算

### 11.1 共同条件

四模式共享原始记录、基础处理工具、工作坐标、诊断字段、可调整参数域、候选登记、指标、独立审核与最终评测器。

诊断卡是实际统计，不含全部原始坐标序列。模型通过受控句柄请求白名单工具，不能读取未授权的原始文件、评测标签或其他模式中间结果。

默认调整域限于第 9 节非负且符合算法定义的网格值及当前明确注册的单项参数策略。模式比较本身不混入额外新算法。

默认每条记录的搜索型模式最多 20 次候选评估，含参考配置；相同预算用于 search-only、llm+search、llm+memory+search。确定性搜索顺序在看到该记录结果前固定，不能由事后人工为某一模式挑更好的序列。

llm-only 只产生一次锁定提议，不补足 20 次搜索；它是无反馈模式消融，不伪称与搜索模式计算量相同。并列报告候选评估预算与实际消耗，不只比较最终分数。

模型模式在共同 24 条 G2\_EVAL 上各做 3 次独立 episode，固定数据与工具条件，每次重置会话与工作记忆。模型可设置 seed 时记录；不能设置时记录 episode\_id，不谎称完全可重复。先在 24 条开发子集验证流程，再锁定正式运行设置。

允许一次真实模型调用批量处理最多 8 张诊断卡以控制成本，但每条记录必须有独立建议、候选 ID、预算和验证结果；不得把一次批量响应写成八次模型调用。所有模式采用相同批量组织原则。

### 11.2 llm-only

只给共同诊断卡、方法定义和合法参数域；不提供当前轨迹的搜索结果、实测评分反馈或案例记忆。

只允许一个真实提议。提议锁定后，由独立确定性工具执行和评分，结果不再反馈给该 episode 的模型修改提议。

“only”不意味着不执行或不评价；它意味着参数决策没有搜索、结果反馈和记忆。不得拿一段模型解释直接当实验结果。

### 11.3 search-only

严格零实验模型调用，不实例化实际可调用模型的隐式依赖，不接受运行中的 A 参数提示。

从共同参考开始，在共同冻结候选域与预算中进行确定性搜索。该模式的输入只有公共合同和自己的确定性观测。

用调用计数和“模型接口一旦被调用即测试失败”的哨兵测试证明零调用，不只在报告中写 0。

### 11.4 llm+search

真实 LLM 提出起点和预期方向；确定性工具执行候选、搜索并返回实际反馈；模型允许据此在批准域内提出下一批候选或停止。

每个 episode 最多 3 个决策回合，且始终受每条记录 20 次候选评估预算约束。第一轮是初始提议，之后最多两轮有真实结果依据的反馈调整。

每一轮保存“看到哪些结果 → 为什么提出当前动作 → 实际执行了什么 → 核验得到什么”。不得预先生成所有响应再伪装成反馈决策。

### 11.5 llm+memory+search

除可读取冻结的示范记忆外，与 llm+search 保持相同模型、提示模板主体、回合、参数域、候选评估预算与停止规则。

记录新增的记忆上下文及成本，不把更大预算带来的差异解释成记忆收益。

### 11.6 所有模式共有的真实性规则

保存原始提议，再核验是否合法；不能先夹紧参数，再声称原始建议全部合法。

越界或无效动作按预登记规则拒绝；允许反馈的模式可在剩余预算内修正。llm-only 不给予额外隐藏修正机会。需要工程回退时单独标记，不能把回退结果算成原提议结果。

默认配置始终是共同参照与合法回退，不因存在 LLM 或搜索就从 Verifier 消失。分别记录 reference、proposal、searched candidates、selected output 和 fallback。

方向预测必须在执行前绑定 metric\_id、参考句柄和 predicted\_sign（升／降／不变），核对的是预登记指标的实测变化，不是把“建议把参数调大”当作正确预测。未承诺预测、指标不可用或数值近零时分别登记，显式报告可评价预测的分母。

最终锁定后的评分不能反向流入当前评测 episode 的候选选择；允许的内部搜索反馈与锁定后评测报告须分开。

## 12. 记忆：真正可用、只读评测、不可自证

保留四层逻辑，但不为每层强行增加模型：

- 工作记忆：当前 episode 的诊断和已尝试动作，结束即重置。
- 情景记忆：已执行、已核验的诊断—参数—实际指标—适用条件记录。
- 程序记忆：从已核验示范经验形成的可解释参数建议／区间或策略索引。
- 人类知识：真实用户／教师来源的解释、证据与反例，只读；没有真实内容就保持空，不由代理冒充人写入。

使用 DEMO\_MEMORY 60 条构建本轮新记忆。初始构建采用冻结的确定性工具与有限搜索；无收益案例可作为经验保存，但必须保留结果性质，不能标为“成功改进案例”。

记忆写入只经确定性核验器准入。LLM 不直接写持久记忆，也不能将自述结论写成事实。

正式 G2\_EVAL 开始前冻结记忆快照，所有模式／重复使用相同版本；评测阶段只读，不从评测轨迹、本轨迹以前 episode 或其他模式结果中积累经验。

检索需要核对父记录及分区、数据与合同版本、诊断特征和适用条件。记录：检索到什么、过滤掉什么、最终传给模型什么、建议是否实际变化。

检索命中不等于被使用；提议变化不等于质量增益；无可用记忆须如实报告，不能人为填入“相似案例”掩盖覆盖不足。

开发阶段发现记忆饥饿，可在 DEMO\_MEMORY 内修正索引、适用性或信息组织后重跑开发验证；不能在看过 G2\_EVAL 结果后扩充示范集再沿用原评测结论。

用运行前后哈希、写操作拒绝测试、同源泄漏测试及跨 episode 隔离测试核实这些约束。

## 13. 单项候选：有限验证，不提前组合

必做三个单项候选：
C-S：只替换分段／短段过滤参数组，其余沿用参考链。
C-D：只替换方向阈值，其余沿用参考链。
C-P：只替换 DP 容差，其余沿用参考链。

这些候选从开发实验中按预登记规则形成，在 G2\_EVAL 上独立评估。允许最终保留参考值，不能为了让候选“不同”硬选更差的参数。

第 9 节的计算可作为候选开发证据，不重复运行以制造独立证据数量；开发选择与留出确认必须分开。

此外，本轮只允许至多两个轻量结构候选，限于以下两类：

1. 基于已核验原始诊断的分层参数策略，相对于统一参数只改变参数选择策略。
2. 在既有教师方向谓词上增加保守删除保护，目的在于减少低位移／不可可靠计算窗口中的不必要删除；不改原值，不使用未知物理限速，不换成迭代删至收敛。

A 必须在实现前登记具体规则、出处、目的、预期收益、成本、风险、额外参数和比较条件，C 审查其是否在上述边界内。阈值只用开发证据确定，不能来自评测效果。

这两类是本 Prompt 的有限候选验证授权，不代表用户已经接受其方法或结果。若没有足够依据形成清晰可验证定义，记录 NOT\_ADMITTED\_WITH\_REASON；三个必做参数单项照常完成，不因缺少一个额外增强而阻断整个 Goal。

不实现文献库中的二十多篇算法，不强制采用某篇方法，不新增神经网络训练、外部数据集、路网、地图匹配、联合时空修复或复杂优化器。既有文献通常只取 2–4 篇有用启发；没有最低采用数量。

每个实际候选必须留下：具体改动、共同基线、开发选择依据、固定参数、留出结果、分组退化、失败例、资源及 KEEP／REJECT／TRADEOFF／INSUFFICIENT 的理由。

## 14. AI 批判、反例与真实案例分析

至少完成一组构造反例的真实运行和前后指标；建议用一个小型统一测试集覆盖：

- 正常急转弯与异常毛刺的区别。
- 零位移、相同时间不同位置、方向不可计算。
- 长时间／距离间断，及简化提前删除断点触发信息。
- 近阈值、有限线段与无限直线距离的差别。
- “删光即可消除异常”和“各自 clean 误差很小即可证明整体更好”的评价漏洞。

构造样例有生成程序、固定 seed 或解析定义、已知答案与适用边界，标为 SYNTHETIC\_COUNTEREXAMPLE / ENGINEERING\_TEST。不能当作原始数据自然发生的错误或总体准确率证据。

有完整人工／生成真值的构造数据可以报告相应误删、漏检或恢复误差；真实数据没有标签则不能套用这些名称。

至少针对 Goal 1 的真实现象完成解释：记录 0、1、2 的整条过滤来自哪个条件；方向删除如何影响局部邻接；DP 近阈值区间如何变化。已有 pilot 是开发案例，不写成独立留出发现。

真实案例同时展示有利、退化和不确定结果。选择规则在生成正式案例图前登记，至少含代表性案例和按预登记指标确定的最差／近边界案例；不只选最好看的。

AI 批判引用实际模型建议或有来源的教学假设，逐条说明核验、修改或拒绝。若模型没有犯某种错误，写“对该风险进行反例检验”，不能伪造模型原话或用户质疑。

生产 A/C 的自动审查是 Agent 互动，不是 Human-in-the-loop。真实用户尚未作出的判断留待网页 GPT 与用户，不用“用户已确认”填空。
