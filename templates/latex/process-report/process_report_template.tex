\section{一般过程：截图汇总}
\begin{contextbox}
一般过程同样保留真实截图，但在正式报告中按阶段汇总。截图是证据主体；文字只说明该阶段解决了什么问题、形成了什么可继续推进的结果。完整原图进入 Evidence Archive。

\section{阶段性总结与下一轮研究}
\begin{contextbox}
Editorial Decision Board 用于阶段总结：背景、关键判断、技术证据与下一步保持在一页内，但不承担复杂分支。它与 Human Reasoning 图和 Candidate Tree 共同构成 Process Diagram Language。
\end{contextbox}

\begin{decisionbox}[C4]
\textbf{Process Report 的核心证据循环：}\quad Idea → Interaction → Human Judgment → Evidence → Decision。一般过程汇总展示，关键过程展开，最终确认必须保留。
\end{decisionbox}

\section{使用边界}
本模板锁定的是视觉语言和证据组织方式，不锁死具体章节名。正式实验中只使用真实任务、真实资料、真实交互和真实实验结果替换示例内容。Process Report 负责“决策如何形成”；Experiment Report 负责“最终方法与实验说明什么”，二者允许共享事实来源，但不复制同一张 Brainstorm 或同一段聊天内容。
