3. **Why β1 can fail, and did DoubleQ solve it?** Feasible-action restriction avoids the invalid assumption that every destination always has an order, but many drivers can still each value the same available best order although only one gets it. This structural competition remains after DoubleQ separates action selection and evaluation.
